Detailed Description

Déclare le moniteur de santé opérationnelle de la station sol.

Le moniteur agrège une fenêtre glissante de trames valides/rejetées et applique deux hystérésis : une sur le taux de rejet et une sur le nombre de télémétries critiques. Les seuils par défaut sont des valeurs de démonstration configurables, pas des limites issues d'une norme spatiale.
