Detailed Description

Fournit un parsing strict et réutilisable des valeurs de ligne de commande STGS.

Les fonctions refusent les suffixes silencieux, les dépassements de capacité et les valeurs flottantes non finies. Cette centralisation évite les conversions permissives de std::stoul/ std::stod qui peuvent accepter une chaîne partiellement valide.
