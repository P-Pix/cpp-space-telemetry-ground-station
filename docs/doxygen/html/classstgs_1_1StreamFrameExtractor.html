Detailed Description

Réassemble et resynchronise des trames STGS dans un flux TCP arbitrairement fragmenté.

Contrairement à UDP, TCP ne préserve pas les frontières de message. L’extracteur conserve les octets incomplets entre appels et recherche le magic STGS après du bruit ou une trame structurellement impossible.

std::vector< ByteVector > stgs::StreamFrameExtractor::feed ( std::span< const std::uint8_t >  bytes)

Ajoute un fragment de flux TCP et restitue les trames complètes disponibles.

Consomme de nouveaux octets TCP et extrait toutes les trames complètes disponibles.

Parameters
bytesNouveau fragment reçu pour la même connexion TCP.
Returns
Zéro, une ou plusieurs trames wire complètes.

Le buffer est resynchronisé sur le magic STGS. Une longueur impossible ne déclenche pas une allocation : un octet est écarté et la recherche de magic reprend sur le flux restant.

Parameters
bytesOctets nouvellement lus sur la socket TCP.
Returns
Liste des candidats de trame complets extraits du flux.
