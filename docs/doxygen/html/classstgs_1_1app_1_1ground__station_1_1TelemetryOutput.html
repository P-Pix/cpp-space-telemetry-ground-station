Detailed Description

Gère le cycle de vie d'un export de télémétrie.

L'objet ouvre le fichier en troncature, écrit l'en-tête adapté au format puis reçoit les trames déjà remises en ordre par le pipeline. La finalisation écrit la fermeture JSON éventuelle et vérifie explicitement le flush() afin qu'une erreur disque ne soit jamais silencieuse.
