Detailed Description

Fournit un flux de diagnostic commun aux threads de la station sol.

Les écritures sont sérialisées par mutex afin de préserver une ligne complète par événement. Les niveaux Warning/Error partent sur stderr, les autres sur stdout ; un fichier facultatif reçoit la même représentation timestampée.
