std::size_t stgs::PortRange::count ( ) const
inlinenoexcept

Retourne le nombre de ports de la plage inclusive.

Une structure PortRange peut être construite directement sans passer par la CLI. L'appel reste donc sûr sur une plage invalide et retourne 0 au lieu de provoquer un sous-dépassement non signé. Les opérations réseau valident néanmoins la plage et lèvent une exception afin de ne jamais masquer une configuration incorrecte.

Returns
Nombre de ports lorsque la plage est valide, 0 sinon.
