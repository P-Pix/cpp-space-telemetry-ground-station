Detailed Description

Convertit SIGINT/SIGTERM en demande d'arrêt depuis un thread ordinaire.

Objectif projet : éviter un gestionnaire de signal asynchrone qui appellerait des primitives C++ non garanties async-signal-safe. Le thread principal bloque SIGINT/SIGTERM avant la création des workers ; un std::jthread dédié les consomme ensuite avec sigtimedwait() et met à jour l'atomic running.

Invariant important : le masque POSIX du thread appelant est toujours restauré, y compris si la construction du thread d'attente échoue ou si une exception remonte depuis le pipeline.
