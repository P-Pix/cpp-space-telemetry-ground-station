Detailed Description

Conserve la première exception produite par un worker et la relaie au thread principal.

Une exception ne doit jamais sortir directement du point d'entrée d'un std::jthread, sous peine d'appeler std::terminate. La première erreur est donc mémorisée, les files sont fermées, puis l'exception est relancée après la synchronisation de tous les workers.
