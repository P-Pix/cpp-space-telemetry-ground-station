Detailed Description

Fournit un diagnostic CLI borné des listeners TCP présents sur le loopback.

L'outil parcourt une petite plage locale, tente une connexion non bloquante sur chaque port, mesure la latence et poursuit systématiquement jusqu'au dernier candidat afin de produire un rapport complet. OPEN signifie "listener TCP joignable" et non "service STGS authentifié".
