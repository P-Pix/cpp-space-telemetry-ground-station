Detailed Description

Déclare le CRC-32/ISO-HDLC utilisé pour l'intégrité des trames STGS.

Paramètres exacts de la variante : width=32, poly=0x04C11DB7, init=0xFFFFFFFF, refin=true, refout=true et xorout=0xFFFFFFFF. Le vecteur de contrôle standard "123456789" produit 0xCBF43926.
