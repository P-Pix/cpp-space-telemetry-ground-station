Detailed Description

Déclare le rendu terminal enrichi utilisé par les outils de démonstration STGS.

La couche détecte automatiquement un terminal interactif, respecte NO_COLOR et retombe sur du texte brut lorsque stdout est redirigé. Les messages reçus sont assainis avant affichage afin qu'un payload distant ne puisse pas injecter de séquence de contrôle ANSI dans le terminal.
