Detailed Description

Définit le modèle métier, le layout wire et les limites d'une trame STGS v1.

Les offsets sont dérivés des tailles des champs afin d'éviter les nombres magiques dans le codec. Un static_assert verrouille la taille du header v1 : toute évolution du protocole doit donc être volontaire et visible en revue de code.
