Detailed Description

Définit la file FIFO thread-safe et optionnellement bornée du pipeline STGS.

Elle relie réception, décodage et écriture. Une capacité non nulle applique une backpressure : les producteurs attendent au lieu de faire croître la mémoire sans limite lorsque le consommateur est temporairement plus lent.
