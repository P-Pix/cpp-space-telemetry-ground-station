Detailed Description

Bloc d'échantillons d'un signal périodique simulé.

Objectif projet : Démontrer un petit pipeline DSP reproductible. Le simulateur crée un sinus, peut y ajouter un bruit gaussien avant transport, puis la station reconstruit/filtre ce bloc et affiche des métriques. Il ne s'agit pas d'une modélisation RF ni d'un modem spatial.

startSampleIndex conserve la phase absolue entre blocs consécutifs ; sans cet index, un filtre corrélatif pourrait introduire une discontinuité à chaque nouvelle trame.
