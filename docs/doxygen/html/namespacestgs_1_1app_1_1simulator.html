Corrompt un octet wire après calcul du CRC afin de simuler une erreur de transport.

Le masque XOR fixe retourne plusieurs bits sans imposer une valeur absolue ; seule la position est pseudo-aléatoire. Cette perturbation est volontairement distincte du bruit gaussien du signal, lequel est injecté avant encodage et doit donc conserver un CRC valide.

Options stgs::app::simulator::parseArgs ( int  argc,
char **  argv 
)

Parse la CLI et effectue les validations qui doivent précéder toute transmission.

Parse la CLI et valide les invariants avant toute transmission ou création de replay.

La fonction vérifie les modes exclusifs, les plages numériques, Nyquist pour le signal, la taille réellement encodable d'un payload STGA et la capacité du compteur absolu d'échantillons. Le simulateur ne commence donc pas une longue émission pour découvrir une incohérence à mi-run.

Exceptions
std::runtime_errorSi la syntaxe, les bornes ou les combinaisons d'options sont invalides.
