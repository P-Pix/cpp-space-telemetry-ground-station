Detailed Description

Définit les primitives internes de sérialisation binaire big-endian.

Ces helpers constituent la couche la plus basse du protocole STGS et du conteneur STGF. Ils évitent de disperser les décalages de bits et les hypothèses d'endianness dans les codecs. Les fonctions de lecture n'effectuent volontairement aucun contrôle de bornes : elles ne doivent être appelées qu'après validation de la taille par le parseur de niveau supérieur.
