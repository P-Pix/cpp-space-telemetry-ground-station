Detailed Description

template<typename T>
class stgs::BlockingQueue< T >

File FIFO thread-safe avec fermeture explicite et backpressure optionnelle.

close() réveille producteurs et consommateurs. pop() renvoie std::nullopt uniquement lorsque la file est fermée et entièrement drainée. Une capacité de 0 conserve le mode non borné, utile pour certains tests/benchmarks ; les exécutables de production utilisent une capacité.
